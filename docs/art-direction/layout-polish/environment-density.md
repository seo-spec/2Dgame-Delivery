# 맵 전역 환경 물체 밀도 보완

2026-11-28. “텅 빈 부분 없이 물체 배치” 요청에 따라 기존 공간 구성 주변과 맵 전역 공터에 고정 환경 물체134개를 추가했다. 도로/입구/배송 접근은 비워 두고 건물 주변에는 생활 소품, 공터에는 크기가 다른 나무와 휴식 소품을 묶었다. 커밋하지 않았다. 새 실행 캡처 이미지를 첨부하지 않았다.

## 배치

| 추가 종류 | 수 |
|---|---:|
| 나무 |60|
| 낮은 화분/녹지 용기 |48|
| 분리수거함 |18|
| 벤치 |5|
| 우편함 |3|
| 합계 |134|

기존 소품37개는 그대로 두어 총171개가 됐다. 건물38개를 합친 환경 인스턴스는209개이며 신호등은 별도다. x0~1200에46개, x1200~2400에44개, x2400~3600에44개를 추가해 출발지에만 몰리지 않게 했다.

data/maps/sample_map.json의 density_props에 ID·종류·위치·크기·충돌을 고정 데이터로 기록했다. 실행 중 무작위 생성하지 않으며 재시작해도 환경 위치는 유지된다. 기존 props와 분리해 원래 배치를 보존했다. 기존 v2 이미지5종을 재사용해 새 PNG나 텍스처 종류를 만들지 않았다.

## 통행과 충돌

- 도로/보도/진입로에서 새 물체의 표시 외곽과 충돌을 모두 고려해12px 이상 여유를 둔다.
- 모든 수령/배송 후보 구역 바깥으로48px 여백을 확보하고, 각 구역에서 가까운 도로까지 폭96px의 접근 통로를 남긴다.
- 출발 위치 주변200×200과 기존 주차칸 주변32px를 비워 둔다.
- 기존 건물/소품과 새 물체 사이에 표시·충돌 외곽 기준12px 이상 간격을 확보했다.
- 나무·벤치·용기처럼 막힌 물체에는 실제 충돌 영역을 함께 추가했다. 보이는 물체를 통과하거나 보이지 않는 장애물만 생기는 구성이 아니다.
- 새 물체가 도로를 막지 않지만, 기존 빈 땅 일부는 실제 환경 장애물이 됐다. 도로 밖을 자유롭게 가로지르던 모든 경로가 유지된다는 뜻은 아니다.
- 기존 건물·소품·도로·충돌·배송 구역·주행 수치·입력 규칙·차량·고객·HUD는 수정하지 않았다.

## 연결과 성능

road_map.py가 기존 props와 density_props를 같은 초기화·공유 캐시·원본 폴백·화면 밖 출력 생략 경로로 읽는다. 새 애니메이션은 추가하지 않았다. 새 물체의 종류별 텍스처가 모두 동일 객체로 공유되고 실제 충돌 목록에도 등록됐음을 런타임에서 확인했다.

현재 전체 맵 설정이 지면 캐시 키에 포함되므로 새 배치에 맞춰25개 사전 생성 캐시를 갱신했다. 검증 도구에서 이전 지면25개와 RGBA가 전부 동일함을 확인했으며 압축 파일 합계도657,520바이트로 같다. 지면을 다시 꾸미거나 기존 연결부를 되돌린 것은 아니다.

실제 SDL1280×720, sync=True, 빈 별도 로컬 캐시 사용:

| 항목 | 실측 |
|---|---:|
| 플레이 초기화 최초 |0.563초|
| 같은 프로세스 재시작 |0.568초|
| 지면 준비 최초/재시작 |0.11/0.12초|
| 캐시 재사용 |25/25, 재생성0|
| update 중앙값(45프레임 표본) |1.42/1.49ms|
| CPU 그리기 중앙값 |5.31/5.65ms|
| 화면 제출 중앙값 |1.70/1.41ms|

최초/재시작 뒤 두 장면의 짧은 표본이다. 화면 제출은 별도로 분리했고, FPS나 최악 프레임의 보장 수치가 아니다. 다른 실행에서는 화면 제출을 포함한 draw가 약24ms였으므로 동기화/표시 조건에 따라 변동할 수 있다. 긴 주행·운석 다수 상황의 성능은 별도 확인이 필요하다. 초기화 시간은 프로세스 실행·타이틀 대기 제외다. 실제 SDL 창은 사용자 입력을 방해하지 않도록 숨겨 실행했다.

추가 GPU 이미지 종류/상주 텍스처는0개(기존 자산 공유)다. 새 물체는 화면 안에 있을 때 개별 이미지1회씩 출력하므로 월드 출력 횟수는 증가한다. 지면에 전부 합성했다고 기록하지 않는다.

## 검증

- py -3.13 -B -m unittest discover -s tests -q: **37개 통과**(기존32+새 배치 안전 검사5).
- 신규 검사: 고유ID/표시/충돌/월드 범위, 도로·보도 여유, 배송·접근 통로, 기존/신규 물체 간 겹침, 출발·주차 공간.
- 기존 HEAD 맵과 비교해 density_props를 제외하면 모든 데이터가 동일하다.
- 실제 SDL에서134개 물체의 출력 객체·충돌 등록·텍스처 공유를 확인했다.
- 수령 후/임박5초/지각5초/실제 배송 완료 검사 통과.
- 기존 지면25개 RGBA 동일 확인.
- 내부 확인에서 건물 주변 생활 소품과 공터 나무가 추가된 것을 확인했다. 결과 문서/답변용 캡처는 추가하지 않았다.
- 테스트는 -B로 실행했고 기존 Python 캐시를 건드리지 않았다.
