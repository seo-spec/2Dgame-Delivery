# 미니맵 아래 운석 경고 배너

- 기존 `warning_bounds()`의140×36px 안에서 청회색 바탕·2px 계단 테두리·밝은 윗면을 적용했다. 미니맵/조작 배너의 예약 영역은 변경하지 않았다.
- 실제 목록에 `FALLING` 운석이 하나라도 있으면 운석 본체/꼬리 기호와 `낙하 중!`, 없으면 삼각형/느낌표와 `운석 예고`를 표시한다. 예고와 낙하가 섞이면 기존과 같은 낙하 우선 조건이다.
- 기존 첫 묶음 경고 강조 조건·6배 시간 위상에 따른 점멸 조건을 그대로 사용하고 테두리와 윗면을 점멸시킨다. 표시 유무·종료 조건·효과음·채널·볼륨·일시정지 처리는 변경하지 않았다.
- 기존 Galmuri 텍스트 캐시를 공유하며 기호는 단순 도형이다. 새 이미지/폰트를 읽거나 매 프레임 이미지를 생성하지 않는다.
- 미니맵·다른 HUD·월드·운석 타이머/규칙은 수정하지 않았다.
- 게임 실행·자동 테스트·커밋은 수행하지 않았다. 실제 배너 글자와 기호 가독성, 예고/낙하 전환은 수동 확인 대상이다.

## 수동 확인

- 첫 예고 때 기존 효과음과 테두리 점멸이 유지되는지.
- 예고→낙하 전환 때 문구·기호가 바뀌는지.
- 예고/낙하가 섞인 때 낙하 표시가 우선하는지.
- 운석 목록이 비거나 성공/실패 시 기존처럼 경고가 사라지는지.
- 미니맵·범례·조작 배너를 침범하지 않는지.
- 일시정지·재개·재시작에서 효과음과 표시가 기존대로인지.
