# 상단 진행 HUD 정리

- 상단 예약 영역은 기존대로 x12~988, 화면 위에서12~64px이며 미니맵·운석 안내·알림 예약 위치는 바꾸지 않았다.
- 도트풍2px 테두리와 계단 모서리, 짙은 청회색 바탕, 크림색 글자·황색 수익·상태별 강조를 사용한다.
- 기존 Galmuri11 폰트로 남은 시간30px, 배송/수익/상태20px, 보조 라벨16px를 표시한다.
- 시간·배송 완료 수·현재/목표 수익·진행 상태를 모두 유지하고 구획을 분리했다. 배송 중30초 이하에서는 타이머 색과 `시간 주의` 문구로 강조하며 점멸은 추가하지 않았다.
- `ProgressHUD`가 상단만 담당한다. 하단 화물·우측 배송·미니맵·월드·시간 및 판정 로직은 변경하지 않았다.
- `CachedFont.draw`에 선택적 `max_width`를 추가했다. 길이가 넘으면 종횡비를 유지한 표시 배율로 축소하며 원문은 자르지 않는다. 폭 제한을 지정하지 않은 기존 호출은 기존 크기로 표시한다.
- 텍스트 캐시를 재사용하고 새 문자열/색 조합이 필요할 때만 캐시를 만든다. 상단 글꼴은 초기화 시 준비하고 종료 시 정리한다. 패널은 단순 도형이며 매 프레임 패널 이미지를 생성하지 않는다.
- 게임 실행·자동 테스트·커밋은 수행하지 않았다. 실제 글꼴 크기·긴 문구의 축소 가독성·알림 겹침은 미확인이다.

## 수동 확인

- 남은 시간이 먼저 읽히고 배송 수·수익·상태가 각각 구분되는지.
- 수령 대기/배송 중/복귀 중/클리어/실패의 문구가 칸 안에 들어오는지.
-30초 이하 타이머 강조와 시간 감소가 정상인지.
- 긴 수익 숫자가 옆 구획을 침범하지 않는지.
- 미니맵·운석 경고·벌금·디버그 안내와 겹치지 않는지.
- 일시정지·재시작·타이틀 복귀 후 폰트와 HUD가 정상인지.
