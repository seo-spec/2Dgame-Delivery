# 클리어 결과창 도트풍 정리

- 기존 결과창 영역(좌하단 원점 x270~730, y264~442)과 재시작 안내/버튼 처리를 유지한다.
- 청회색 패널·2px 계단 테두리·밝은 윗면·민트 강조선을 현재 HUD 팔레트로 통일했다.
- 제목 `STAGE CLEAR`30px, 배송 수20px, 최종 수익30px, 목표 달성 여부18px로 우선순위를 나눴다. 기존 정보와 수치는 모두 유지한다.
- 라벨/값 영역을 분리하고 긴 배송 수·수익·목표 문구는 기존 텍스트 캐시의 `max_width`로 축소 표시한다. 새로운 이미지나 글꼴을 로드하지 않는다.
- 기존 메뉴/본문/상단 라벨·값·타이머 캐시를 공유한다. 클리어 판정·보상·입력·다른 HUD·월드는 수정하지 않았다.
- 현재 도트풍 건물 교체는 배달소와 `collision_preview_house`1채에만 연결되어 있다. 다른 기본 주택·상점·카페·아파트·파란 집은 기존 자산을 사용한다. 이번에는 건물을 교체하지 않았다.
- 게임 실행·테스트·커밋은 수행하지 않았다. 실제 폰트 높이·긴 수치 축소 가독성은 미확인이다.

## 수동 확인

- 제목·배송 수·수익·목표 달성 여부가 결과창 안에서 구분되는지.
- 긴 수익과 목표 숫자가 테두리 밖으로 넘치지 않는지.
- 재시작 안내가 결과창과 겹치지 않고 R 입력이 기존대로인지.
- 클리어 후 일시정지/재개·타이틀 복귀가 기존대로인지.
