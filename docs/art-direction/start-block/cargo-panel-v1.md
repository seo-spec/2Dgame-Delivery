# 하단 화물 상태 패널 도트풍 정리

- 기존 하단 영역 x12~988, y12~120 안에 화물 카드5개를 배치한다. 기존 배송지 순서와 식별을 유지한다.
- 상단/우측과 같은 청회색 바탕, 크림 글자,2px 계단 테두리와 밝은 윗면을 사용한다.
- 카드 위: 배송지 식별·적재 상태. 가운데: 화물 아이콘·이름. 아래: 내구도 수치·바.
- 수령 대기=회색과 `수령 대기`, 적재=민트(내구50% 미만 적색)와 `적재`, 파손=적색 테두리/`파손`/느낌표, 완료=민트 테두리와 `완료`로 구분한다.
- 실제 내구도 수치·완료 우선 상태 규칙은 유지한다. 바의 표시만0~1로 제한하며 화물 계산값은 변경하지 않는다.
- 카드별 표시 폭 제한으로 긴 배송지 식별·화물명·내구 수치가 밖으로 넘치지 않게 한다. 수치는 파손 느낌표 자리도 남긴다.
- 기존 HUD 본문18px와 상단 보조16px Galmuri 캐시, 화물 아이콘 캐시를 공유한다. 신규 폰트·이미지를 로드하거나 매 프레임 패널 이미지를 만들지 않는다.
- 상단·우측 HUD·월드·화물/배송 규칙은 변경하지 않았다.
- 게임 실행·자동 테스트·커밋은 수행하지 않았다. 실제 합성 화면과 긴 이름의 축소 가독성은 수동 확인 대상이다.

## 수동 확인

- 화물5개 카드가 하단 영역 안에 표시되고 기존 알림과 겹치지 않는지.
- 수령 전 빈 슬롯/수령 대기와 수령 후 아이콘/화물명이 정상인지.
- 적재·내구50% 미만·파손·완료 상태를 구분할 수 있는지.
- 긴 이름·내구 수치가 옆 카드나 파손 기호를 침범하지 않는지.
- 배송 완료·재시작 후 표시와 기존 상단/우측 패널이 정상인지.
