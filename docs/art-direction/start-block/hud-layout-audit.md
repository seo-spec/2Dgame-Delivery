# 인게임 HUD 배치 코드 점검

기준: 설정1280×720, 플레이1000×720 + 우측280px. 코드와 데이터만 읽어 점검했다. 게임 실행·자동 테스트·커밋은 하지 않았다.

## 영역 — 왼쪽 위 원점의 화면 좌표

| 요소 | X | Y | 코드상 예약/폭 처리 |
|---|---|---|---|
| 상단 진행 HUD |12~988|12~64| 시간/배송/수익/상태 구획, 각 텍스트 폭 제한 |
| 하단 화물 카드5개 |12~988|600~708| 카드 간격8px, 이름/상태/내구 수치 폭 제한 |
| 우측 배송 패널 |1000~1280|0~720| 카드5개: 각각 높이104px, 간격114px, 마지막 하단650px |
| 미니맵 |776~984|80~288| 중심(880,184), 반경104, 축척 유지 |
| 운석 경고 |810~950|298~334|140×36px, 텍스트 최대92px |
| 미니맵+경고의 배너 회피 영역 |768~992|72~344| 기존 `overlay_bounds()` |
| 조작/상태 배너 후보 |20~980 범위|80~588 범위| 폭520/400/300, 높이는 줄 수에 따라 결정. 주요 표시와6px 간격 검사 |
| 완료 결과창 |270~730|278~456| 내부 문구 시작x292, 이번에 최대416px로 제한 |

기본 해상도의 고정 패널끼리 겹치는 구간은 코드에서 확인되지 않았다. 배너는 후보 영역 전체를 덮는 패널이 아니며 회피 조건에 따라 일부 위치만 사용한다. 모든 후보가 가려진 경우 해당 프레임에서 안내가 생략될 수 있다.

## 상태별 점검

| 상황 | 코드에서 확인한 처리 | 이번 조치/한계 |
|---|---|---|
| 긴 시간/수익/화물명 | 상단/우측/하단은 `max_width`로 표시 폭 제한 | 변경 없음. 축소된 실제 글자의 가독성은 미확인 |
| 지각 | 별도 상태 문구·초과시간·기분과 아이콘 구획 분리 | 변경 없음. 실제 글꼴 행 높이는 미확인 |
| 파손 | 하단 상태·테두리·느낌표, 수치 오른쪽 여백 확보 | 변경 없음. 실제 표시 밀도는 미확인 |
| 완료 | 카드 문구와 기분 유지, 결과창에 긴 숫자 폭 제한이 없었음 | 결과창 문구만 폭 제한 추가. 정보와 결과 계산 유지 |
| 실패 | 원래 사유를 공통 배너에서 줄바꿈, 재시작 안내와 우선 배치 | 변경 없음. 복수 배너의 위치 이동/생략 빈도는 미확인 |
| 복귀 | 배달소 안내, 실제 복귀는 자동 판정 | 변경 없음. 조작 키를 새로 요구하지 않음 |
| 벌금+조작 안내 | 경고90, 조작70 우선순위로 별도 빈자리 배치 | 변경 없음. 고객/차량이 밀집한 화면은 미확인 |
| 일시정지 | 일반 배너는 추가로 그리지 않고 기존 메뉴 표시 | 변경 없음. 재개 후 시각적 잔상은 미확인 |

## 수정: 수령 전 목적지 위치 노출

NPC/머리 위 느낌표는 이미 수령 전 숨겼지만, 다음3경로는 상태 검사 없이 남아 있었다.

1. `ZoneMarkers.draw()`에서 배송 구역 바닥선·기호 출력.
2. `play_mode.draw()`에서 실제 집의 이름표 출력.
3. `MiniMap.draw()`에 전체 배송지 목록을 전달해 목적지 점과A~E를 출력.

수령 대기에서는 배달소 수령 기호만 그린 뒤 목적지 마커 처리를 끝내고, 집 이름표/미니맵에는 빈 표시 목록을 사용한다. 보이지 않는 집 이름표를 조작 배너 회피 영역에도 넣지 않는다. 실제 `delivery_houses` 데이터는 변경하지 않는다.

화물 수령 후 배송 상태가 되면 기존 목적지 바닥선·NPC·느낌표·집 이름·미니맵 목적지를 표시한다. 수령 전에도 일반 건물 지형과 배달소·플레이어는 유지한다. 우측/하단의5개 대기 카드와 게임 내부 목적지 추첨·마감·수령/배송 판정은 유지한다.

## 수동 확인 항목

- 시작/재시작 직후 월드의 배송지 바닥선·집 이름·NPC·느낌표·미니맵 목적지 점/A~E가 없는지.
- 배달소 수령 위치·일반 건물 지형·플레이어·5개 대기 카드는 유지되는지.
- 수령 직후 목적지 표시가 함께 나타나며 실제 배달 구역과 일치하는지.
- 지각/파손/완료/복귀/실패 상태에서 카드 정보와 배너가 잘리지 않는지.
- 긴 수익 숫자가 완료 결과창 안에 들어가는지.
- 미니맵 범례·운석 경고·여러 목적지 이름표의 실제 글꼴 겹침은 없는지.
- 일반창/전체화면에서 글자가 충분히 읽히고 배너 위치 변화가 어색하지 않은지.

현재 작업 전부터 남아 있던 운석 배너 변경과 Python 캐시는 이번 점검에서 되돌리거나 수정하지 않았다.
