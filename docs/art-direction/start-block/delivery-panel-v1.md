# 우측 배송 패널 도트풍 정리

- 기존 우측280px, 배송지5개와 순서를 유지한다. 상단·하단·월드·배송 판정은 변경하지 않았다.
- `progress_hud.py`의 청회색 바탕·크림 글자·민트/황색/적색 강조 팔레트를 재사용한다.2px 테두리와 계단 모서리로 카드5개를 구분한다.
-720px 높이에서 카드 상단630px, 카드 높이104px, 간격114px로 배치한다. 다섯 번째 카드 하단70px, 아래에는 임박/지각 범례를 둔다.
- 각 카드에 배송지 이름, 상태, 남은/초과시간, 기분, 화물 종류와 아이콘을 표시한다. 수령 전에는 `수령 대기`와 `배송 시작 전`, 화물은 `수령 전`으로 표시한다.
- 마감10초 이내는 `! 마감 임박`, 기존 규칙상 마감 초과는 `! 지각`과 초과초를 표시한다. 임박 기준은 표시용이며 고객 기분·마감·보상 규칙은 그대로다.
- 완료는 완료 문구·민트 테두리로 구분하고 실제 배송 완료 당시 고객 기분을 유지한다.
- 이름·상태·시간·기분·화물 이름 각각의 표시 폭을 제한하며 긴 원문은 텍스처 표시 배율만 줄여 칸에 맞춘다.
- 기존 HUD 본문18px와 상단 HUD의 라벨16px/값20px 캐시를 빌린다. 새 폰트/아이콘을 별도 로드하지 않고 기존 화물 아이콘 캐시도 공유한다. 패널에서 빌린 자원을 별도로 종료하지 않는다.
- 게임 실행·자동 테스트·커밋은 하지 않았다. 실제 글꼴 높이·긴 문구 가독성·아이콘 배치는 수동 확인 대상이다.

## 수동 확인 항목

- 배송지5개가 잘리지 않고 화면 우측280px 안에 들어오는지.
- 수령 전/진행/임박/지각/완료 각 상태에서 이름·시간·기분·화물을 읽을 수 있는지.
- 마감10초 전과 마감 초과 시점의 강조가 맞는지.
- 화물명·시간 숫자가 길어져도 카드와 아이콘을 침범하지 않는지.
- 완료 당시 기분 유지와 재시작 후 대기 표시가 정상인지.
- 상단·하단·미니맵·기존 알림이 이전대로인지.
