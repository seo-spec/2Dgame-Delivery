# 서쪽 인접 지면 확장과 다음 완성도 개선 순서

## 선정 구역

- 추가 구역: 월드 x0~300, y200~1500. 기존 x300~1200, y200~1500의 서쪽에 붙는300×1300 구역이다.
- 최근 도트 자산을 재사용한 기본 주택(150,450), (150,750)의 주변 지면을 포함한다. 건물 위치·표시·충돌은 바꾸지 않는다.
- 합성 범위를 x0~1200, y200~1500으로 넓혀 기존 `RoadFinish` 텍스처1개에서 준비한다. 별도 오브젝트/텍스처를 겹치지 않으므로 x300의 내부 페이드 이음부가 없어진다.
- 패턴과 포장 격자는 월드 좌표에 고정되어 같은 위치에서 이어진다. 기존 구역 x300~396 부근의 옛 왼쪽 페이드는 제거되므로 해당 구간도 완성 재질로 보인다. 이것은 연결을 위한 의도된 차이다.
- 월드 끝 x0에서는 기본색으로 되돌아가는 페이드를 끄고, 바깥 지면이 있는 우측·상단·하단에는 기존96px 페이드를 유지한다.
- 건물·소품·고객·HUD, 도로 형상/충돌/수령/배송 판정은 변경하지 않았다. 매 프레임 파일 로딩/이미지 생성 없이 초기화 시 합성하고 화면 밖 출력은 생략한다.

## 메모리·출력 횟수 — 계산값, 미측정

| 항목 | 기존 | 확장 후 | 증가 |
|---|---:|---:|---:|
| RGBA 크기 |900×1300|1200×1300|300×1300|
| 원시 텍스처 바이트 |4,680,000|6,240,000|1,560,000|
| MiB |4.46|5.95|1.49|
| 정적 지면 텍스처 개수 |1|1|0|

드라이버/정렬 오버헤드는 포함하지 않는다. 초기화용 픽셀·마스크 버퍼도 크기 증가에 비례해 늘지만 생성 뒤 보관하지 않는다. 초기화 시간과 실제 프레임 시간은 측정하지 않았다.

## 전체 완성도에 대한 후속 작업

이 평가는 코드와 자산을 읽은 결과이며 최신 전체 실행 화면에 대한 평가가 아니다.

1. **입구와 배송 공간의 연결**: 현재 기본 주택 자산은 지붕 위주이며 입구 표현이 약하다. 고객이 서 있는 구역과 건물 사이에 문턱·짧은 진입부·같은 방향의 입구를 맞춰 공간의 용도를 읽게 하는 작업을 다음으로 선정한다. 첫 대상은 북쪽 주택(750,900)1개다. 판정과 도로는 유지한다.
2. **시점·접지 통일**: 나무와 부드러운 차량/일부 소품, 미교체 건물은 새 도트 지면과 화풍이 섞여 있다. 출발지 한 화면을 기준으로 실제 보이는 자산부터 정리한다. 막연한 애니메이션 추가보다 실루엣·명암·시점을 먼저 맞춘다.
3. **한 화면의 완성도 확인**: 같은 카메라/상태의 수동 캡처로 빈 공간 비율·고객과 차량 크기 관계·목적지 가독성을 비교한다. 이는 후속 수동 확인 항목이며 이번에는 실행하지 않는다.

장식·건물 위치·도로 폭을 한 번에 재배치하는 작업은 이번 확장 범위에 포함하지 않는다. 다음 작업도 주택 입구1개처럼 효과를 구분할 수 있는 단위로 진행한다.

## 수동 확인

- (150,450), (150,750) 주변에 동일한 풀·포장 재질이 나오는지.
- x300을 가로지를 때 줄눈/무늬가 이어지고 색상 띠가 없는지.
- x0 월드 끝과 외부 페이드 경계에 그늘/밝은 직사각형이 보이지 않는지.
- 이동/재시작 후 정상 표시되고 도로·건물 충돌·수령/배송 판정이 기존대로인지.

게임 실행·자동 테스트·커밋은 수행하지 않았다. 실제 경계/패턴의 가독성과 전체 화면의 완성도는 미확인이다.
