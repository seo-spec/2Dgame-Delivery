# 출발지 길·풀 재질 2차 정리

## 타이틀 자산과 비교

`assets/images/title/title_city_v1.png`를 직접 확인했다. 타이틀은 차분한 아스팔트 면, 크림색 사각 포장판/줄눈, 모양이 있는 풀 덩어리로 재질을 구분한다. 기존 인게임은 매 픽셀 입자·규칙적인 잔디 색 격자와 작은 가로 포장 블록이 중심이었다.

## 적용

- 기존 개선 구역 x300~1200, y200~1500, 기존96px 바깥 경계 페이드를 유지한다.
- 잔디의 넓은 색 격자를 제거하고3가지 손으로 정한 잎 덩어리 패턴을 월드2px 격자 위에 드문드문 배치한다. 좌표별 위치/패턴/좌우 반전을 결정하며 게임 난수 상태는 건드리지 않는다.
- 기본색은 바깥 지면과 같은 `GRASS_COLOR=(75,112,82)`를 사용한다. 잎면 변화는-2/+4, 작은 이음부-6 정도로 제한해 큰 사각형이 밝거나 어둡게 보이지 않게 한다.
- 아스팔트의 전면 입자와 넓은 사인파 명암을 제거하고128px 구획 중 일부에만 작은 저대비 자국을 넣는다.
- 보도는24×24px 사각 포장판, 마당은32×32px 판으로 변경한다.2px 줄눈·좌상단 밝은 면·우하단 어두운 면으로 읽히게 하고 픽셀별 입자는 없앤다.
- 연석과 잔디 접점의 어두운 면 강도를 줄이고 도로 표시는 차분한 크림색으로 정리한다. 표시의 기존 위치/폭 처리와 판정 형상은 유지한다.
- 출발 위치와 실제 수령/배송 구역 주변에서는 풀/도로 자국을 생략하고 포장판 대비도 기존처럼 줄인다.

## 범위와 성능

- 패턴은 코드에 정의한 정적 데이터이며 PNG 원본/타이틀 자산은 수정하지 않았다. 이미지 생성 도구는 사용하지 않았다.
- 기존 `RoadFinish` 초기화 시 마스크/재질을 합성하고 동일900×1300 RGBA 텍스처1개에 업로드한다. 메모리 계산상 약4.46MiB, 기존과 같이 화면에 걸릴 때1회 출력한다. 런타임 프레임 비용 측정값은 아니다.
- 화면 밖 출력 생략과 초기화 후 이미지 재사용을 유지한다. 매 프레임 파일 로딩/재질 이미지 생성은 없다.
- 도로·건물·소품 위치/크기·충돌·수령/배송 판정·고객·HUD는 변경하지 않았다. 새 포장/풀 무늬는 도로 판정에 들어가지 않는다.
- 게임 실행·자동 테스트·커밋은 하지 않았다. 실제 화면의 패턴 반복감·경계 밝기·마커 대비는 미확인이다.

## 수동 확인

- 잔디가 넓은 격자나 점 노이즈보다 낮은 대비의 풀 덩어리로 보이는지.
- 포장판과 아스팔트가 건물·차량·고객보다 튀지 않는지.
- 좌우/위아래 개선 구역 경계가 그늘이나 밝은 사각형처럼 보이지 않는지.
- 이동 시 패턴이 지면에 고정되고 포장 이음새가 끊기지 않는지.
- 수령/배송 표시와 기존 도로 이탈·충돌·신호 판정이 정상인지.
