# 일시정지 메뉴 도트풍 정리

- 기존 메뉴항목 `Resume / Restart / Exit`, 제목 `PAUSED`, 키보드 안내를 유지한다.
- 기존 화면 중앙 기준 패널 범위(cx±205, cy-215~cy+190)를 유지하고 청회색 바탕·2px 계단 테두리·밝은 윗면을 적용했다.
- 버튼은 기존 `pause_button_bounds()`가 반환하는320×56px 범위 그대로 그린다. 버튼 위치·클릭 영역·입력 처리는 변경하지 않았다.
- 선택 항목은 민트 테두리·세로 강조선·도트 화살표·밝은 글자로 구분한다. 비선택 항목은 같은 패널 계열과 보조 글자색을 쓴다.
- 기존 Galmuri30px 메뉴 캐시와18px 본문 캐시를 재사용한다. 항목/제목/안내에는 표시 폭 제한을 적용한다. 새 이미지나 글꼴은 로드하지 않는다.
- 기존 배경 빗금과 일시정지·재개·재시작·타이틀 이동, 마우스/방향키/Enter/Esc 처리는 변경하지 않았다. 다른 HUD·월드도 변경하지 않았다.
- 실행 테스트·자동 테스트·커밋은 수행하지 않았다. 실제 글자 배치·선택 화살표 가독성은 미확인이다.

## 수동 확인

- Esc로 열기/닫기, 방향키 선택과 Enter 실행이 기존대로인지.
- 마우스 이동/클릭이 기존 버튼 범위에서 정상인지.
- 선택 표시와 글자가 잘 보이고 버튼 밖으로 넘치지 않는지.
- Resume/Restart/Exit가 각각 기존 재개/재시작/타이틀 이동을 수행하는지.
- 일시정지 중 시간·운석·효과음 정지와 재개 동작이 기존대로인지.
