# 미니맵 도트풍 테두리와 범례

- 기존 중심 좌표·반경104·월드 축척(`MAP_CONTENT_RADIUS=82`)·북쪽 고정 좌표 변환을 유지한다.
- `overlay_bounds()`와 `warning_bounds()`를 변경하지 않아 운석 안내·조작 배너의 예약 영역은 그대로다.
- 상단/우측 HUD의 청회색 바탕·계단 테두리·크림/민트/황색/적색 팔레트를 사용한다. 테두리의2px 행 데이터는 초기화 시 준비한다.
- 플레이어: 민트 방향 삼각형과 밝은 중심점. 배송 전: 황색 사각형과 A~E 이름. 완료: 민트 체크와 A~E 이름. 배달소/복귀의 기존 이름과 링 표현은 유지한다.
- 운석 예고는 점멸 링+느낌표, 실제 차단은 링+X로 구분한다. 실제 운석 목록·잔여시간·차단 해제 비율·점멸 조건은 그대로 참조한다.
- 원 내부 여백에 북쪽N과 하단2줄의 나/배송/완료/위험 범례를 배치한다. 지도 위 이름표의 세로 배치 범위만 조정해 범례와 분리했다. 지도 점과 지형 좌표는 옮기지 않는다.
- 기존 Galmuri 텍스트 캐시를 공유하며 범례는 표시 폭만 줄인다. 새 파일을 로드하거나 매 프레임 이미지를 생성하지 않는다. 지도와 기호는 기존처럼 단순 도형을 그린다.
- 다른 HUD·월드·이동/배송/운석 규칙은 변경하지 않았다.
- 게임 실행·자동 테스트·커밋은 하지 않았다. 작은 범례의 가독성·복잡한 목적지/운석 겹침은 수동 확인 대상이다.

## 수동 확인

- 미니맵 위치·크기·축척과 플레이어/목적지의 지도 좌표가 이전과 같은지.
- 플레이어 방향·미배송 사각형·완료 체크·배달소/복귀를 구분할 수 있는지.
- 하단 범례·지도 이름표·북쪽 표시가 테두리 안에서 잘 보이는지.
- 운석 예고와 차단X가 구분되고 차단 해제 시 표시가 정상적으로 사라지는지.
- 미니맵 아래 운석 안내와 조작 배너가 기존 예약 영역을 지키는지.
