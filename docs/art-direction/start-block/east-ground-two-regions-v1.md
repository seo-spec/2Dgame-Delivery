# 동쪽 배송 경로 지면 2구역 확장과 배달소 화단 제거

## 적용 범위

| 구역 | 표시 좌표 (left,bottom,right,top) | 선정 이유 |
|---|---|---|
| 기존 | (0,200,1200,1500) | 출발지와 북쪽 기본 주택 주변 |
| 동쪽 1 | (1200,200,1800,1500) | (1450,1050) 주택과 y450/750/1350 가로 도로 주변 |
| 동쪽 2 | (1800,200,2400,1500) | (2250,1050) 상점과 x1950·y450/750/1350 도로 주변 |

기존 맵의 도로 연결과 건물/배송 구역 데이터를 참고했다. 실제 배송지는 실행 시 선택될 수 있으므로 위 건물을 고정 배송 순서로 만들지 않는다. 합친 표시 범위는 (0,200)~(2400,1500)이다. 북쪽 y1500 이후와 동쪽 x2400 이후는 기존 바닥으로 전환된다.

## 정적 합성과 경계

- 기존 grass_color, asphalt_shade, RoadFinish의 보도·연석·작업 마당·조용한 배송 구역 마스크를 그대로 재사용한다. 이미지 자산을 새로 생성하지 않았다.
- 기존 텍스처를 하나의 대형 텍스처로 늘리지 않고 기존 구역과 동쪽 두 구역을 초기화 시 각각 합성·업로드해 보관한다. 카메라 이동 시 다시 생성하지 않는다.
- 풀 무늬·아스팔트 자국·포장 줄눈·페이드의 기준은 월드 좌표다. 내부 경계 x1200/x1800에는 페이드를 넣지 않고 합친 범위의 바깥쪽에만 기존 96px 페이드를 사용한다. 월드 왼쪽 끝에는 기존처럼 페이드하지 않는다.
- 연석/도로 가장자리의 이웃 픽셀 계산을 위해 각 재질 텍스처에 사방 2px 여백을 추가한다. 출력은 clip_draw로 여백을 제외한 정확한 원래 구역만 그려 중복 알파 합성과 밝은 줄을 방지한다.
- 현재 세 구역은 빈틈없이 맞닿아 하나의 직사각형을 이룬다. 페이드 범위는 이 조건에 맞춰 계산한다. 향후 불연속 구역이나 L자 배치에는 별도 외곽 처리 검토가 필요하다.
- 기존 진입부 전용 작은 텍스처는 여백 0으로 유지하고, 지면 뒤에 가려지지 않도록 재질 출력 다음에 그린다.
- 각 구역은 자체 표시 범위로 화면 밖 출력 생략을 한다. 로드/업로드 실패 시 해당 재질만 생략되고 기존 지면은 남는다. 실패 시 내부 재질 단절 가능성은 수동 확인 대상으로 둔다.

## 메모리와 출력 예상

RGBA 4바이트/픽셀 기준이며 GPU 실측값이 아니다.

| 항목 | 저장 텍스처 크기 | RGBA 환산 |
|---|---|---:|
| 기존 구역, 여백 포함 | 1204×1304 | 6,280,064바이트 |
| 동쪽 1, 여백 포함 | 604×1304 | 3,150,464바이트 |
| 동쪽 2, 여백 포함 | 604×1304 | 3,150,464바이트 |

새 두 텍스처 합계는 6,300,928바이트다. 기존 텍스처에 추가한 여백 증가분 40,064바이트까지 포함한 순증가는 6,340,992바이트, 약 6.05MiB다. 초기화 중 마스크·픽셀 버퍼 등의 임시 CPU 메모리는 이 수치와 별도이며 구역별 생성 후 해제된다. 초기화 시간이 늘어날 수 있으며 실행 측정하지 않았다.

추가 출력은 두 구역이 모두 화면에 걸칠 때 최대 2회, 화면 밖이면 0회다. 기존 지면 재질까지 포함하면 최대 3회이며 기존 도로 도형·진입부 출력은 그대로다. 매 프레임 이미지 생성·파일 로딩은 없다.

## 화단 제거

사용자가 제공한 화면과 맵 배치를 기준으로 배달소 옆 (620,280)의 planter 1개를 제거했다. 이 오브젝트의 100×100 이미지와 90×30 충돌 영역이 함께 사라져 보이지 않는 장애물을 남기지 않는다. 다른 화단 4개는 현재 planter_pixel_v1.png를 공유하는 도트 자산이므로 유지한다. 원본 이미지와 공통 도트 이미지는 삭제하지 않았다.

화단 삭제로 해당 충돌만 제거되며 다른 소품·건물 충돌, 도로 형상·판정, 배송 구역·조건, 고객·입력·HUD·게임 규칙은 변경하지 않았다. 맵 변경은 재질 확장 좌표와 이 화단 삭제뿐이다.

## 수동 확인

- x1200과 x1800을 넘을 때 풀·도로·보도에 어두운 띠, 밝은 줄, 반복 패턴 단절이 없는지.
- 동쪽 1/2 구역의 (1450,1050), (2250,1050) 건물과 배송 고객/마커가 잘 보이는지.
- x2400, y200, y1500의 바깥쪽 경계가 기존 바닥으로 자연스럽게 이어지는지.
- 기존 문턱·진입부가 재질에 가려지지 않는지.
- 배달소 (620,280)의 화단이 사라지고 그 자리에 보이지 않는 충돌이 없는지.
- 나머지 화단·건물·고객·HUD와 도로/배송 입력 판정이 유지되는지.
- 재시작과 카메라 이동 후 누락·잘림이 없는지, 초기 로딩 시간이 허용 가능한지.

실행 테스트와 커밋은 하지 않았다. 최신 제공 화면은 화단 확인에만 사용했으며 확장 후 실제 화면·프레임 성능·초기화 시간은 미확인이다.
