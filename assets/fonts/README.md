Galmuri11 글꼴을 타이틀·HUD·일시정지 메뉴 등 게임 전체에서 사용한다.

- 제작자 quiple
- 버전 2.40.4
- 공식 배포 https://github.com/quiple/galmuri/releases/tag/v2.40.4
- 원본 파일 `Galmuri-v2.40.4.zip`의 `Galmuri11.ttf`
- 라이선스 SIL Open Font License 1.1, 원문은 `Galmuri-LICENSE.txt`에 포함

공통 경로는 `game/config/fonts.py`에서 관리한다. 화면별 글자 크기는 기존 설정을 사용한다.
